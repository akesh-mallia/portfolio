Automated Hydraulic Load Application

2026

Background

My team has a pull-test fixture used to apply a tensile load on a separation system. The goal of this fixture is to measure preload. However, it has a long runtime because load is currently being manually applied via a lever hydraulic pump. My project is to automate load application via a control system.

The system consists of a pump, motor, solenoid control valve, solenoid relief valve, and other valves and fittings. It is operated via a National Instruments (NI) computer running LabVIEW.

Challenges

01

Getting past solenoid stiction

Problem
Small valve commands produced no load change until a threshold was reached. Load then jumped, often overshooting the ramped setpoint. I suspected static friction in the spool.
Solution
I added Gaussian white noise to the control signal as dither, keeping the spool in the realm of kinetic friction. I also reduced the load increase rate and removed the integral term on increasing load.
Outcome
The stepped response on load increase was improved.
02

Keeping progress moving while parts shipped

Problem
Selecting parts for the entire system meant coordinating multiple vendors. Procurement took 2 weeks longer than I expected.
Solution
I worked in parallel: while hardware was on order, I wrote the LabVIEW state machine and modeled the system in NX.
Outcome
The wait became development time, with software being plug and play as soon as the hardware arrived.

Results

Successful load application within setpoint requirements

Automated control of load with a ramp and soak setpoint profile.

Decreased runtime from 1 hour to 5 minutes

Saved engineer time by automatically adding load to the system and acquiring data. Especially important as this is a test that is conducted for every production unit.
